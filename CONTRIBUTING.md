# Contributing

Thanks for helping make these guides better.

- **Found a mistake?** Open an issue with the **Guide fix** template. Include the file and the error message.
- **Built a project?** Open an issue with the **Project showcase** template and link your repo.
- **Pull requests** for fixes are welcome — keep changes small and explain why in the description.

Please don't upload datasets to this repo. Link to the source instead.
